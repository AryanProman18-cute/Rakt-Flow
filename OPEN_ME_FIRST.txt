RaktFlow V3.2 portable source archive

This is a standard ZIP with repository files directly at the archive root.
The preferred V3 interface and the existing Firebase, Neon, Render, Vercel,
and GitHub architecture are preserved.

For the existing deployment, start with APPLY_V3_2_UPDATE.md.
Apply only migrations/004_integrated_workflows.sql to the existing Neon database.
Do not reset Neon and do not recreate deployed services.

For a new deployment, leave the Vercel Root Directory blank and read
APPLY_V3_2_UPDATE.md plus docs/DEPLOYMENT_V3_2.md. New databases apply
migrations 001, 002, 003, and 004 in order.

Never commit or share passwords, API keys, database credentials, or Firebase
service-account JSON.
